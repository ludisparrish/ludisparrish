# BUG-003: Order history page does not exist — navigation option is missing

**Severity:** Major  
**Priority:** Medium  
**Status:** Open  
**Environment:** Chrome / macOS  
**Found in:** https://automationexercise.com

## Steps to reproduce
1. Log in as TestUser01
2. Place at least one order
3. Attempt to navigate to order history

## Expected result
Order history page is accessible and displays
placed orders with order ID, date and status.

## Actual result
Order history page does not exist.
No navigation option or link to order history
is available anywhere in the UI.
User has no way to view past orders.
